Guitar Detuning Calculator

Compare your current tuning with a target tuning. Enter notes from the thickest string (6) to the thinnest string (1).

Your tunings

Standard tuning: E A D G B E. You can type spaces or compact notes such as EADGBE.

Examples: DADGAD, DADF#AD, CGCGCE. Use # for sharp or b for flat, e.g. F#.

String-by-string adjustments

Changes use the nearest pitch with the same note name, within ±6 semitones. Add octave numbers if you need to specify an exact register (e.g. E2 A2 D3 G3 B3 E4).

Tip: For the clearest result, include octave numbers in both fields. Without octave numbers, the calculator assumes the closest pitch movement. This tool calculates note changes; it does not listen to your guitar.
